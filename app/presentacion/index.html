07 · Bajo el capó

RAG híbrido + un LLM open-weight local.

01 · REESCRIBE

Entiende

Qwen convierte la pregunta coloquial en terminología jurídica.

Qwensin razonamiento
02 · BUSCA

Recupera

Búsqueda léxica y semántica, fusionadas con Reciprocal Rank Fusion.

BM25 · SQLite FTS5embeddingsRRF
03 · RESPONDE

Cita

Redacta con citas [n] a los fragmentos y transmite la respuesta en tiempo real.

streaming SSEcitas a página
04 · ACTÚA

Genera

Si pides un documento: tool call, tarjeta de confirmación y servicio externo.

tool callingJSON SchemaHTTP
Navegador⇄ FastAPI⇄ Ollama · Qwen 27B (Mac Studio)+ Servicio de documentos· Docker / Coolify
Ventanilla · v1

Por dentro es un RAG híbrido en cuatro pasos: reescribe la pregunta, busca con BM25 y embeddings fusionados con RRF, responde con citas y, si pides un documento, hace una tool call.

Todo corre con un modelo open-weight, Qwen, en hardware propio vía Ollama.

11 · Extensible por diseño

Cuatro puntos para conectar lo que sigue.

config/sources.yamlYAML

Fuentes

Una ley, una ficha de trámite o una página de gob.mx es un bloque de YAML. Parsers incluidos: ley, fichas SAT, HTML y genérico.

→ CURP, pasaporte, IMSS, INFONAVIT, PROFECO…
config/document_services.yamlJSON Schema

Documentos

Un esquema define a la vez la tool del LLM, la validación y el formulario de confirmación.

→ Queja ante PROFECO, renuncia voluntaria…
POST /v1/documentsContrato HTTP

Servicios

Cualquier generador que hable el contrato: respuesta lista, inline, asíncrona o archivo directo.

→ El servicio real de una dependencia o de un tercero
LLM_BASE_URL · LLM_MODELAPI OpenAI

Modelos

Cualquier servidor compatible con la API de OpenAI. Cambiar de modelo es cambiar una variable.

→ Ollama, vLLM, LM Studio, llama.cpp
Ventanilla · v1

Hay cuatro puntos de extensión: fuentes, documentos, servicios y modelos. Los dos primeros son YAML; los otros dos, un contrato HTTP y una variable de entorno.

12 · Así de fácil

Un trámite nuevo = un bloque de YAML.

config/sources.yaml+ nueva fuente
- id: curp
  title: "Consulta e impresión de la CURP"
  short_title: CURP
  institution: RENAPO
  url: https://www.gob.mx/curp/
  format: html
  parser: html
$ python -m app.rag.ingest --only curp
→ el chat ya puede responder y citar sobre la CURP
config/document_services.yaml+ nuevo documento
- id: queja_profeco
  title: Queja ante PROFECO
  service: generador
  parameters:
    type: object
    properties:
      consumidor_nombre: {type: string}
      proveedor: {type: string}
      hechos: {type: string}
      peticion: {type: string}
    required: [consumidor_nombre, proveedor, hechos, peticion]
→ el LLM ya tiene la tool generar_queja_profeco

Ejemplos ilustrativos basados en las ideas de CONTRIBUTING.md. Un documento nuevo también necesita su plantilla en el servicio de documentos (mock_doc_service/templates.py).

Ventanilla · v1

Agregar una fuente es un bloque de YAML y un comando de ingesta. Agregar un documento es otro bloque con su JSON Schema: el LLM obtiene la tool, la validación y el formulario sin escribir más código.
